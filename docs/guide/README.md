# CIMS for a hardware store

This guide covers the work a hardware store does in CIMS: selling at the counter, keeping the
stockroom straight, and knowing where the shop stands.

It is written for whoever is doing the job, not for whoever built the system. Every screen in
it was photographed from a running shop, and every message in the troubleshooting page was
produced by actually causing the problem.

## What this guide does not cover

**Separate logins for cashiers and stockmen.** The shop currently has one account, with the
**Owner** role. CIMS can restrict what each person sees, but those roles have not been set up,
so everyone signs in as the owner and can reach everything. [Add a staff
account](18-add-a-staff-account.md) explains how to create accounts; deciding who should be
restricted to what is a decision for the shop.

**Printing to a receipt printer.** The receipt appears on screen and the **Print** button opens
your browser's print window. No thermal printer was attached when this guide was written, so
the printed slip is not shown here.

**Selling on Shopee or Lazada.** The marketplace screen exists and is described nowhere in this
guide, because connecting it needs seller accounts the shop does not have yet.
